# Changes

This file lists the changes compared to the original v 6.06 release and some procedures.

## Adding parameters

I used vesc tool motor configuration parameter editor to generate the param files. 

- Added the params in `Param editor mcconf` in VESC tool
- After that in the same window:
  - File->Save XML as to backup the changed version of the parameters
  - Tools->Export configuration parser to create a parser for C to use (use confgenerator as name, no prefix)

This creates some files that help with modifying the existing code. However, they are not perfect, as they only contain the mcconf (motor config) parts.
We need to manually merge this.

### Confgenerator.c

This file contains the serializers, deserializers and defaults for both appconf and mcconf. The confparser.c generated by VESC tool needs to be merged into the confgenerator.c at the root of the project. This can be done best using a merging tool like winmerge. In the end, almost everything in the generated file should be included in the file in the root folder (rule of thumb: everything with a changed parameter name). Order matters.,

### Confgenerator.h

The only thing to be changed in the header file is a fingerprint. `CONFGENERATOR_SIGNATURE` from confparser.h shows this value. It should be copied to `MCCONF_SIGNATURE` in confgenerator.h.

### datatypes.h

In the `mc_configuration` struct in `datatypes.h` add the fields that were added. For example:

```h
// Parking brake params - can only be used if motor_type is MOTOR_TYPE_DC
bool dc_enable_parking_brake;
float dc_parking_brake_current;

uint16_t rpm_filter_cutoff;
float min_current_pll_detection;
```

  - However, this file only includes the mcconf parts
  - Using a tool like WinMerge, observe the difference between the files.

Copy in res/config folder latest version

also in fw.xml

#### Deploying VESC-tool

To deploy the VESC tool, copy the exe from the release build path to another directory. Then execute 

```ps
    &"C:\Path\To\Qt\5.15.2\mingw81_64\bin\windeployqt.exe"
    "C:\Path\To\DeployFolder\vesc_tool_7.00.exe" `
    --qmldir C:\Path\To\QmlDirectory
```

windeployqt can be installed by installing Qt 5.15.2 MinGW 64‑bit with the QT online installer.

## Code changes

- `confgenerator_serialize_mcconf` in `confgenerator.c` below `buffer[ind++] = conf->sensor_mode;`:

    ```c
    buffer[ind++] = conf->dc_enable_parking_brake;
    buffer_append_float32_auto(buffer, conf->dc_parking_brake_current, &ind);
    ```

- `confgenerator_deserialize_mcconf` in `confgenerator.c` below `conf->sensor_mode = buffer[ind++];`:

    ```c
    conf->dc_enable_parking_brake = buffer[ind++];
    conf->dc_parking_brake_current = buffer_get_float32_auto(buffer, &ind);
    ```

- `confgenerator_set_defaults_mcconf` in `confgenerator.c` below `conf->sensor_mode = MCCONF_SENSOR_MODE;`:

    ```c
    conf->dc_enable_parking_brake = false;
    conf->dc_parking_brake_current = 0;
    ```

- In `confgenerator.h` change the define to (this may be dependent on the version of the config, please check with VESC tool through procedure described above)

    ```h
    #define MCCONF_SIGNATURE     1250443276
    ```

- In `mc_configuration` struct in `datatypes.h` add below `mc_sensor_mode sensor_mode;`:

    ```h
    // Parking brake params - can only be used if motor_type is MOTOR_TYPE_DC
    bool dc_enable_parking_brake;
    float dc_parking_brake_current;
    ```

- change version in `conf_general.h`. Max allowed value is 255.255.
- Surround all things referencing `TIM_Channel_2` by this condition: `if (conf->motor_type != MOTOR_TYPE_DC || !conf->dc_enable_parking_brake)` In some places this can be simplified (e.g. in `commutate`) if a part or the whole of outcome of the condition is fixed. Also change `TIM1->CCR2` in `update_timer_attempt` to

    ```c
    if (conf->motor_type != MOTOR_TYPE_DC || !conf->dc_enable_parking_brake){
        TIM1->CCR2 = timer_struct.duty;
    }
    ```
